# INSAT C Programming Labs & Solutions 

Welcome! This repository contains a complete collection of C programming lab assignments (*Atelier Programmation*) and homework solutions for the **MPI** track at **INSAT**.

This version was built, debugged, and refined collaboratively **with my friends and peers** to help future generations of students navigate their programming labs with clean, working code.
